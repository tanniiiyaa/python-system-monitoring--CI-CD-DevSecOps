# Upstream application

This DevSecOps implementation uses the public Python System Monitoring application as its application source:

https://github.com/Aj7Ay/Python-System-Monitoring

The upstream repository is the source of the Flask application, tests, Docker build files, Makefile, and application assets.

This repository adds the project-specific Jenkins CI/security pipeline and AWS deployment documentation around that application.
